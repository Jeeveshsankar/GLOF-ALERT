# GLOF Alert - Early Warning and Disaster Monitoring System

## Project Overview

GLOF Alert is a mobile application designed to provide early warnings and real-time alerts for Glacial Lake Outburst Floods (GLOF). The system focuses on disaster risk reduction, public safety, and environmental monitoring, particularly for flood-prone and high-risk regions.

Glacial Lake Outburst Floods pose a serious threat to downstream communities. Delayed alerts and lack of awareness often lead to loss of life, infrastructure damage, and environmental impact. GLOF Alert addresses this problem by delivering timely alerts, location-based risk information, and emergency preparedness guidance through a reliable mobile platform.

## Key Objectives

- Provide early warnings for potential GLOF events
- Improve disaster preparedness and public awareness
- Deliver real-time alerts to affected regions
- Support emergency response and risk mitigation efforts
- Build a scalable and reliable disaster alerting system

## System Architecture

The system follows a layered architecture to ensure scalability and maintainability:

### Data and Monitoring Layer
- Environmental and flood-related data sources
- Risk assessment inputs based on location and alert status

### Application Layer
- Mobile application developed using Flutter
- Real-time alert notifications
- Location-based risk monitoring
- Emergency safety instructions and guidelines

### Notification Layer
- Push notifications for emergency alerts
- Visual warning indicators and status updates
- Provision for future SMS-based alert integration

## Installation

### Prerequisites
- Flutter SDK (version 3.22 or higher)
- Dart (version 3.4 or higher)
- Android Studio or VS Code with Flutter extension

### Steps
1. Clone the repository
   ```
   git clone https://github.com/jeeveshsankar/glof-alert.git
   cd glof-alert
   ```

2. Install dependencies
   ```
   flutter pub get
   ```

3. Run the application
   ```
   flutter run
   ```
